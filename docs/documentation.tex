\section{Overview}
A Raspberry Pi that reads a GNSS receiver, applies RTK corrections from an NTRIP caster,
and serves the corrected position over the network. It is reachable remotely through NetBird.

\section{Install on a New Pi}
Repo paths under \texttt{pi/} mirror the Pi's filesystem.
\begin{verbatim}
cd pi/src && make && sudo make install     # ntrip_rtk, gpscmd, can_reader
sudo cp ntrip-rtk.service /etc/systemd/system/
sudo install -m 600 ntrip-rtk.example /etc/default/ntrip-rtk
sudo nano /etc/default/ntrip-rtk        # fill in NTRIP_USER/PASS
sudo systemctl daemon-reload && sudo systemctl enable --now ntrip-rtk
\end{verbatim}
Optional overrides: \texttt{GPS\_DEV}, \texttt{NMEA\_TCP\_PORT}, \texttt{GGA\_INTERVAL}.

\section{Useful Commands}
\begin{verbatim}
journalctl -u ntrip-rtk -f              # fix / sats / caster status
sudo systemctl restart ntrip-rtk
mmcli -m any                            # LTE modem status
sudo netbird status
\end{verbatim}

\section{Next Steps}
\begin{enumerate}
  \item Outdoors: confirm GNSS fix (\texttt{journalctl -u ntrip-rtk -f}, \texttt{sats} $> 0$).
  \item Install a SIM; outdoors, confirm LTE registers and \texttt{wwu1i4} gets an address; check both antennas are attached.
  \item If LTE stays weak: consider enabling bands 5 and 66.
  \item RTK: contact the caster provider, switch to another caster (e.g.\ RTK2go), or build own base station.
  \item Security: revoke the NetBird setup key in the dashboard (already removed from the Pi and the repo).
\end{enumerate}

\section{Own Base Station (option)}
Base receiver (Quectel LC29H(BS) or u-blox ZED-F9P) with a multi-band antenna at a fixed point near the track,
streaming RTCM3 to the car via 915\,MHz/LoRa radios (no internet needed) or via its own NTRIP caster over NetBird.
Survey-in 5--30\,min before a run; gives cm-level accuracy relative to the base.
